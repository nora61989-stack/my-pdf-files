مقدمة

عندما نفتح أي موقع إلكتروني فإن أول ما يلفت انتباهنا هو شكله: ألوانه وخطوطه وترتيب عناصره على الشاشة. لغة HTML مسؤولة عن هيكل المحتوى، أما CSS فهي المسؤولة عن المظهر والتصميم.

1- أساسيات CSS وطرق ربطه بالصفحة

تتكون قاعدة CSS من محدد (Selector) يحدد العنصر المستهدف، وخصائص (Properties) وقيمها. 

h1 {
    color: navy;
    font-size: 32px;
}

هناك ثلاث طرق لإضافة CSS إلى صفحة HTML:

الطريقة مكان الكتابة الاستخدام
Inline داخل العنصر نفسه تعديل عنصر واحد
Internal داخل وسم Style صفحة واحدة
External ملف منفصل style.css جميع صفحات الموقع

2- كيف نغيّر الألوان

تستخدم CSS خاصية color للتحكم في لون النص، وخاصية background-color للتحكم في لون الخلفية، كما يمكن استخدام border-color للحدود.

  • اسم اللون مثل red وtomato.
  • HEX مثل #1a4d8f.
  • RGB وRGBA.
  • HSL.

3- كيف نغيّر الخطوط

تتحكم CSS في شكل النص من خلال مجموعة من الخصائص:

  • font-family: نوع الخط.
  • font-size: حجم الخط.
  • font-weight: سمك الخط.
  • font-style: شكل الخط.
  • line-height: المسافة بين الأسطر.
  • text-align: محاذاة النص.

4- كيف نغيّر تصميم الموقع (Layout)

يوجد أكثر من أسلوب للتحكم في تصميم الصفحة:

  • Box Model: نموذج الصندوق.
  • Flexbox: ترتيب العناصر في صف أو عمود.
  • CSS Grid: تقسيم الصفحة إلى صفوف وأعمدة.
  • Responsive Design: التصميم المتجاوب مع الشاشات.

الخاتمة

تعد CSS الأداة الأساسية التي تحول صفحة HTML البسيطة إلى موقع جذاب ومنظم. فبتغيير الألوان نعبّر عن هوية الموقع، وبتغيير الخطوط نحسن القراءة والانطباع، وباستخدام Flexbox وGrid وMedia Queries نضمن ظهور الموقع بشكل مرتب على جميع الأجهزة.
